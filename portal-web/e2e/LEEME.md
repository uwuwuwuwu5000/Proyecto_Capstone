# Pruebas de pantalla (Playwright)

- `npx playwright test --list`: lista las pruebas sin ejecutarlas.
- `npm run test:e2e`: levanta los emuladores y ejecuta las pruebas (desde la fase 2).
- `npm run test:e2e:ui`: modo visual para depurar.
- Evidencia oficial: `EVIDENCIA_DIR=../Evidencia npm run test:e2e` deja el JUnit en esa carpeta.
